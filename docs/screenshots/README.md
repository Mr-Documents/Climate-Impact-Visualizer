# Screenshots Directory

This directory contains screenshots for the Climate Impact Visualizer README.

## Required Screenshots

1. **dashboard-overview.png** - Main dashboard displaying real-time environmental KPIs and risk assessments
2. **geospatial-analysis.png** - Interactive map with precipitation, temperature, and wind velocity overlays
3. **historical-trends.png** - 30-year climate evolution with statistical trend analysis
4. **risk-predictions.png** - AI-generated flood, drought, and thermal stress risk forecasts

## Screenshot Guidelines

- **Resolution**: 1920x1080 or higher
- **Format**: PNG (recommended) or JPG
- **Quality**: High resolution, clear text
- **Content**: Show actual application interface with realistic data
- **Naming**: Use the exact filenames specified above

## How to Capture Screenshots

1. Run the application locally: `npm start` in the frontend directory
2. Navigate to each major section of the application
3. Use your operating system's screenshot tool or a tool like Snagit
4. Save images to this directory with the specified filenames
5. Ensure sensitive information (API keys, personal data) is not visible
